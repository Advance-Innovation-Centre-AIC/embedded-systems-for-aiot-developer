# AIoT in Action — Embedded Systems for AIoT Developer

> เรียน **AIoT** จากของจริงบนบอร์ด **BENTO PSoC Edge — Eva Kit หรือ TESAIoT Dev Kit** ด้วยภาษา **MicroPython** — แตะฮาร์ดแวร์จริง อ่านเซนเซอร์จริง แล้วส่งขึ้นแพลตฟอร์ม IoT ที่ติดตั้งเอง · ตัวอย่างชุดเดียวกันรันได้ทั้งสองบอร์ด เพราะโค้ดถามบอร์ดเองว่ามีไฟกี่ดวง ปุ่มชื่ออะไร และมีเซนเซอร์อะไรบ้าง

### ดูสไลด์ออนไลน์ (ไม่ต้องติดตั้งอะไร)

**https://advance-innovation-centre-aic.github.io/embedded-systems-for-aiot-developer/**

## สำหรับใคร

หลักสูตรนี้ออกแบบสำหรับ **นิสิตภาควิชาวิศวกรรมระบบสมองกลฝังตัว และภาควิชาวิศวกรรมไฟฟ้า คณะวิศวกรรมศาสตร์ มหาวิทยาลัยบูรพา**

แนวคิดคือ **Principle to Application** — เริ่มจากเล่นแอปพลิเคชันที่ทำงานได้จริงบนบอร์ดก่อน ให้เห็นว่าปลายทางหน้าตาเป็นอย่างไร แล้วจึงค่อย ๆ แกะลงไปทีละชั้นจนสร้างเองได้ทั้งวงจร:

**จอสัมผัส → ฮาร์ดแวร์ → เซนเซอร์ → เครือข่าย → MQTT → TESAIoT Platform**

12 คาบ คาบละ 3 ชั่วโมง กลุ่มละ 3–4 คนต่อบอร์ดหนึ่งตัว (ทุกคนใช้ BENTO Emulator ในเครื่องตัวเอง และหมุนเวียนกันนั่งบอร์ด) MicroPython ล้วน ไม่ต้องคอมไพล์ ไม่ต้องสู้กับ toolchain ของภาษา C

## โครงหลักสูตร

| ตอน | คาบ | เนื้อหา |
|---|---|---|
| **1 · Existing UI-based Application** | 1–2 | รู้จักบอร์ดและทุกอย่างที่ Python สั่งได้ · ค่าที่วัดบนโต๊ะนี้ไปโผล่บนเครื่องคนอื่น |
| **2 · UI-to-Hardware Interfacing** | 3–5 | GPIO + LCD · Touch UI ที่คุมไฟจริง · อนาล็อกและสัมผัส (pot, CapSense, ฟิลเตอร์) |
| **3 · Sensor Visualization on HMI** | 6–8 | เครื่องวัดระดับดิจิทัลจาก IMU · กราฟ real-time · Mini-HMI Dashboard |

| **5 · Edge AI on Device** | 11–12 | เลือก รัน อ่านผลโมเดล AI ด้วย `edge_ai` · ส่งผล AI ขึ้น MQTT และรับคำสั่งกลับ |

เปิด [roadmap](https://advance-innovation-centre-aic.github.io/embedded-systems-for-aiot-developer/) เพื่อดูการ์ดของทั้ง 12 คาบ พร้อมภาพหน้าจอจริงของผลงานแต่ละคาบ

## โค้ดภาษา C คู่กับทุกไฟล์ MicroPython

ทุกไฟล์ `.py` ในรีโปนี้มีไฟล์ `.c` ชื่อเดียวกันวางอยู่ข้างกัน เป็นโค้ด C ที่เขียนด้วยมือ ทำงานแบบเดียวกับไฟล์ `.py` ทั้งหน้าจอ ข้อความ ไฟ และจังหวะเวลา เขียนตามกฎ **MISRA C:2012** และ **Clean Code** ของไลบรารี BENTO (`CLEAN_C.md`) ส่วนบนของแต่ละไฟล์บอกว่าเป็นคู่ของไฟล์ `.py` ไหน และจุดไหนที่ภาษา C ต้องทำต่างไป

### วิธีรัน

1. เปิด BENTO IDE ที่ [ide.bentoedge.com](https://ide.bentoedge.com) แล้วไปที่แท็บ **C**
2. กดนำเข้าไฟล์ (Import files) แล้วเลือกไฟล์ `.c` ถ้ามีไฟล์ `.h` ชื่อเดียวกันให้เลือกมาด้วย
3. กด **Run on Emulator** เพื่อลองบน BENTO Emulator หรือกด **Program to Device** เพื่อส่งขึ้นบอร์ด

เฟิร์มแวร์ที่รันโปรแกรม C ได้: Dev Kit 2.7.0 ขึ้นไป, Eva Kit (MicroPython) 1.10.0 ขึ้นไป, Eva Kit (Game) 1.6.0 ขึ้นไป

### ข้อจำกัดใน BENTO Emulator ตอนนี้

Edge AI, MQTT และแพลตฟอร์ม TESAIoT จากภาษา C ยังไม่มีใน Emulator โปรแกรมจะขึ้นข้อความบอกบนจอ แล้วทำงานต่อตามเส้นทางเดียวกับไฟล์ `.py` เช่น การ์ด "ไม่มีโมเดลบนบอร์ดนี้" หรือโหมดออฟไลน์ บนบอร์ดจริงทุกส่วนทำงานครบ

### การตรวจที่ทุกไฟล์ผ่าน

- คอมไพล์สำหรับ PSoC Edge ด้วย arm-none-eabi-gcc โดยถือ warning เป็น error
- คอมไพเลอร์ในเบราว์เซอร์ของ BENTO IDE ทั้งสำหรับบอร์ดและสำหรับ Emulator
- cppcheck 2.17.1 กฎ MISRA C:2012 ไม่เหลือข้อที่ผิด นอกจากข้อยกเว้นใน `c_twins_deviations.txt` และข้อยกเว้นของไลบรารี
- clang-tidy 20 และ clang-format 20 ตามค่าตั้งของไลบรารี

### ไฟล์ที่ไม่มีคู่ภาษา C

- `examples/lvgl_ports/part1/main_loader.py`, `examples/lvgl_ports/boot/main_loader.py` และ `examples/lvgl_ports/sec3_sensor_viz/menu_sec3.py` ไฟล์เหล่านี้มีหน้าที่สั่งรันไฟล์ `.py` อื่นด้วย `exec()` ซึ่งภาษา C ทำไม่ได้ ส่วนเมนูอื่นที่มีคู่ภาษา C จะแสดงหน้าจอและปุ่มเหมือนเดิม แต่บอกว่า C สั่งรันไฟล์ `.py` ไม่ได้
