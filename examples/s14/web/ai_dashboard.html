คาบ 12 · ผล AI ขึ้น MQTT ทันที

ผล AI สด · 4 ชุด Smart HMI

บอร์ดส่งผล AI ขึ้น broker → หน้านี้ฟังหัวข้อของทีมแล้วแสดงทันที · ส่งคำสั่งเปลี่ยนโมเดลกลับไปได้
บอร์ดedge_ai → JSON→ brokerbroker.hivemq.com→ หน้าเว็บนี้MQTT ผ่าน WebSocket
กำลังโหลดไลบรารี MQTT… ใส่ชื่อทีมแบบเดียวกับ TEAM ในโค้ดบอร์ด แล้วกดเชื่อมต่อ

4 ชุด Smart HMI · ตอนนี้เป็นอย่างไร (กดแถวเพื่อเลื่อนไปที่การ์ด)

ชุด (ช่อง kit)ตอนนี้

ชุดและโมเดลตามตัวอย่าง Smart HMI ของคาบ 11 · ข้อความที่ไม่มีช่อง kit (ตัวอย่าง 01–03 ของคาบ 12) ขึ้นที่การ์ด “ทั่วไป” · เงียบเกิน 10 วินาที = ออฟไลน์ (บอร์ดส่ง heartbeat ทุก 2 วินาที)

ผลล่าสุดของแต่ละชุด

ยังไม่มีข้อความจากบอร์ด
รันตัวอย่างบนบอร์ด (เช่น examples/s14/01_ai_to_mqtt.py) ที่ตั้ง TEAM เป็นทีมเดียวกับช่องด้านบน
แล้วกดเชื่อมต่อ · หน้านี้ฟัง bento-aiot/<TEAM>/ai

ส่งคำสั่งกลับไปที่บอร์ด (ตัวอย่าง 03)

หัวข้อ bento-aiot/<TEAM>/ai/cmd
ยังไม่ได้ส่งคำสั่ง · ส่งแบบ QoS 0 และไม่ retain · ห่างกันอย่างน้อย 3 วินาที (บอร์ดไม่รับคำสั่งที่ถี่กว่านี้)

บอร์ดทำตามเฉพาะชื่อที่อยู่ใน ALLOWED และมีบนบอร์ดจริง · ทำเสร็จบอร์ดส่งสถานะที่ …/ai ทันที ช่อง model คือคำตอบว่าทำแล้ว (หยุดอยู่ = "")

เส้นเวลา (50 รายการล่าสุด · ใหม่อยู่บน)

  1. ยังไม่มีเหตุการณ์

ข้อความดิบล่าสุด (แสดงเป็นตัวอักษรเท่านั้น)

ยังไม่มีข้อความ
broker สาธารณะไม่เข้ารหัส · ใครรู้ชื่อหัวข้อก็ส่งข้อความปลอมเข้ามาได้ หน้านี้จึงข้ามข้อความที่ไม่ใช่ JSON และใส่ทุกค่าลงจอเป็นตัวอักษร ไม่เคยแปลงเป็น HTML
หน้าตาข้อความที่หน้านี้อ่าน 
# bento-aiot/<TEAM>/ai  ตัวอย่าง 01 (ไม่มี kit → การ์ดทั่วไป)
{"id": "team05", "n": 12, "model": "AnomalousVibration", "label": "anomaly", "conf": 87}
# ชุด HMI ของคาบ 11 เพิ่ม kit · state · events
{"id": "team05", "n": 40, "model": "AnomalousVibration", "label": "anomaly", "conf": 91,
 "kit": "machine", "state": "alert", "events": 3}
# ตัวอย่าง 02 ใช้ "alarm": 0/1 แทน state · 03 หยุดอยู่ = "model": "" และ "label": "-"
# bento-aiot/<TEAM>/event  ตัวอย่าง 02
{"id": "team05", "event": "ai_alarm_start", "model": "AnomalousVibration", "label": "anomaly", "conf": 91}
