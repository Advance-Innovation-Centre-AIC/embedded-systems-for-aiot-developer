# examples/widgets — widget ทีละตัว สำหรับทดสอบบนบอร์ดจริง

ไฟล์ในโฟลเดอร์นี้สาธิต **widget ตัวเดียวต่อหนึ่งไฟล์** ให้สั้นที่สุดเท่าที่ยัง
เห็นว่ามันทำอะไรได้ ไม่ผูกกับคาบไหน ไม่มีเรื่องราวประกอบ

**มีไว้เพื่อสองอย่าง**

1. **ทดสอบบนบอร์ดจริง** — อัปโหลดไฟล์เดียว รันแล้วดูว่า widget ตัวนั้นวาดออกไหม
   กดแล้วตอบไหม บนฮาร์ดแวร์จริง ไม่ใช่บนตัวจำลอง
2. **เป็นชุดตรวจสุขภาพ** หลังแก้ไลบรารี — ถ้าไฟล์ไหนพัง แปลว่า widget ตัวนั้นเสีย
   โดยไม่ต้องเดาว่าพังเพราะอะไรในตัวอย่างที่ซับซ้อนกว่า

**ต่างจาก `examples/sNN/` อย่างไร** — ไฟล์ในคาบสอนแนวคิด และใช้ widget เป็น
เครื่องมือเล่าเรื่อง ส่วนไฟล์ที่นี่สอน widget ตัวนั้นเอง ไฟล์เดียวจบ

## วิธีรันบนบอร์ด

อัปโหลดไฟล์เดียวเป็น `/main.py` แล้วรีเซ็ต หรือวางในหน้า Playground ของ BENTO IDE

## กติกา

- หนึ่งไฟล์ต่อหนึ่ง widget ตั้งชื่อตาม widget
- ต้องรันจบเองได้ ไม่ค้างรอ input ไม่ต้องต่อเน็ต
- ข้อความเป็นภาษาไทย เพราะฟอนต์ไทยคือจุดที่ widget พังบ่อยที่สุด
- ตามระบบออกแบบใน `SPEC.md` §S7.13 — ตัวอักษรจาก {28, 24, 20} เท่านั้น
  เป้าสัมผัสไม่ต่ำกว่า 88 px กริด 8

โฟลเดอร์นี้ได้รับยกเว้นจาก `tools/check_orphan_examples.py` เหมือน `usecase/`
เพราะไม่ได้ผูกกับคาบใดคาบหนึ่ง
